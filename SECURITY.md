## Reporting a vulnerability

Report a vulnerability in private with [GitHub private vulnerability reporting](https://github.com/kanzifucius/xr-rollout-controller/security/advisories/new).

Include the impact, the commit you tested (`main` until a tag exists), and steps to reproduce if you have them. Do not open a public issue or pull request for an unfixed vulnerability.

Maintainers will acknowledge the report on the advisory. If you have not heard back, comment on the advisory rather than opening a public issue.
